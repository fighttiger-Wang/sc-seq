# 多组学跨软件生物学因果链条编排规范 (Multi-Omics Synthesis & Causal Chain Protocol)

在面对包含多种生物信息学分析软件输出的综合数据集时，严禁按照软件输出目录逐一罗列“流水账”。报告必须以**组织微环境演变与疾病病理学核心科学假说**为中轴，将各个软件的分析结果像齿轮一样咬合在一起，构建完整的因果解释闭环。

---

## 一、跨软件多维齿轮咬合体系

| 分析维度 / 软件输出 | 提取指标 | 串联角色 | 强制咬合与因果传递逻辑 |
| :--- | :--- | :--- | :--- |
| **Seurat / Scanpy** | 亚群细胞比例、ROE 偏好性 | **【表型现象】** | 明确在疾病或干预条件下，哪群细胞发生特征性耗竭？哪群细胞发生异常克隆性膨胀？确立核心靶细胞。 |
| **MAST / FindMarkers** | 差异表达基因（DEGs, Log2FC） | **【内在驱动】** | 深入靶细胞内部：该细胞表型变化的分子驱动是什么？特征性激活了哪些效应分子（如水解酶、表面受体）或丢失了哪些结构蛋白？ |
| **clusterProfiler / GSEA** | 通路富集（NES, FDR, Q-value） | **【功能机制】** | 这些差异分子协同驱动了何种系统性细胞代谢或应激重构？（如缺氧应激、糖酵解重编程、内质网应激、焦亡）。 |
| **CellChat / CellPhoneDB** | 配受体对（L-R pairs, p-value） | **【外在互作】** | 代谢重构的靶细胞如何作为 Sender 向邻近细胞发送求救/招募信号？靶受体细胞如何被激活并反向反馈损伤？ |
| **Monocle / Slingshot** | 拟时序轨迹（Pseudotime, 分支） | **【时间演进】** | 这一病理表型是跳跃突变还是连续演化？沿假时间轴的初始起点、过渡中间态与终末病理锁定位点在哪里？ |
| **SCENIC** | 转录因子调控子活性（Regulons） | **【转录主控】** | 驱动上述分化轨迹与基因重塑的“分子总开关”转录因子是谁？维持稳态的转录调控子如何失活？ |
| **Spatial / Stereo-seq** | 空间微环境（Niche / Colocalization） | **【空间落地】** | 上述配受体对话与表型转换到底发生在组织的哪一层？（内膜剥离面、中膜断裂区、外膜血管床）。 |

## 二、标准四阶学术叙事编排结构

无论输入的数据包含上述哪几种模块，正文编排均应遵循如下四阶递进逻辑：

### 第一阶：组织稳态失衡与宏观细胞消长（Phenotype Discovery）
* **输入依据**：全局大类与亚群比例表、ROE 嗜性热图、全局 UMAP 图。
* **写作规范**：阐述各大类与亚群在不同组别中的相对丰度消长与观察/期望偏离。指出哪个结构细胞丢失最为严重、哪个免疫/基质亚群反应最为剧烈。

### 第二阶：细胞内在转录紊乱与功能极化（Intracellular Driving Force）
* **输入依据**：亚群差异基因表（DEGs）、火山图、GO/KEGG/GSEA 通路富集表。
* **写作规范**：严密咬合第一阶发现的靶细胞，探查其内部功能紊乱。结合具体的标志基因（如收缩骨架、促炎酶类）和显著富集通路（如 Hypoxia, Glycolysis, ECM degradation），阐明细胞发生表型转换（Phenotypic Switching）的内在动力。

### 第三阶：微环境细胞互作与跨系对话闭环（Microenvironment Crosstalk）
* **输入依据**：CellChat / CellPhoneDB 通讯强度柱状图、配受体气泡图、通路信号网络图。
* **写作规范**：将靶细胞放入组织微环境中，解析“结构细胞—免疫细胞”或“上皮—基质”双向交互。必须明确列出关键配体-受体对（如 MIF–CD74/CXCR4, CCL2–CCR2, TNF–TNFRSF1A），阐明信号发送端与接收端的协同破坏或代偿机制。

### 第四阶：命运演化时间轴与转录主控网络（Developmental Trajectory & Regulons）
* **输入依据**：Monocle 拟时序树状图/拟时间着色 UMAP、SCENIC 调控子热图/活性柱状图。
* **写作规范**：建立病理发展的动态因果链条。描述细胞从生理成熟态向病理终末态的演化分支，并揭示调控子（如 MYOCD 下调伴随 KLF4/NF-κB 上调）作为分子开关的调控机理。

## 三、跨软件串联的三大禁忌

1. **严禁割裂罗列**：绝不能写成“3.1 差异基因分析结果显示... 3.2 通路富集显示... 3.3 细胞通讯显示...”。必须融合成“3.1 血管壁中膜平滑肌缺氧重构与单核细胞招募轴”。
2. **严禁无细胞归属的通路解读**：解读 GSEA/KEGG 时，必须指明是在哪一个具体的细胞亚群中富集，不能脱离细胞载体空谈通路。
3. **严禁无物理互作证据的机制推演**：解读细胞间通讯时，必须以实测配受体强度为依托，不可凭空假设未经检验的旁分泌作用。
