# 🧹 项目长期治理与体检除草指南 (`govern.js` / 口令 `g`)

> **适用范围**：项目经过多轮 Vibe Coding 迭代后，出现代码文件越来越长、过期过程文档堆积、死代码残留或样式硬编码反弹时，用户输入单键 **`g`** 即可一键触发。  
> **设计渊源**：1:1 吸收 `oil-dev-skills` 中 `oil-govern` (`audit_repo.py`) 的核心精髓。

## 1. 一键运行体检脚本

```bash
node "<SKILL_DIR>/scripts/govern.js" <项目目录> [--clean-snapshots] [--json]
```

## 2. `govern.js` 四大自动化体检维度

1. **📏 单文件超长臃肿预警（> 300 行分层瘦身）**：
   - 自动扫描项目中所有 `.js/.ts/.tsx/.jsx/.vue/.html/.css` 源码文件；
   - 标出超过 **300 行**（预警）和 **500 行**（高危臃肿）的大文件，指导按“视图组件 / 状态逻辑 / 样式 Token”进行分层拆分。
2. **🧟 冗余死代码与孤儿文件扫描**：
   - 扫描未被任何入口文件引用的孤儿脚本/样式文件；
   - 扫描文件中定义了但全仓引用次数为 0 的废弃辅助函数（死代码候选）以及残留的调试语句（`console.log` / `debugger` / `TODO`）。
3. **📚 累计过期混乱文档与死链治理**：
   - 盘点项目根目录与 `docs/` 下的 Markdown 文档体积（检查 `AGENTS.md` / `DESIGN.md` 是否超过 10KB 预算）、最后修改时间温差及失效的相对链接死链；
   - 识别临时评审草稿、过程备份（如 `.r3-verify`、`*评审报告*.md`、`*.bak`），建议归档至 `docs/archive/`。
4. **🎨 硬编码与规范偏离巡检**：
   - 统计源码中散落的裸 Hex/RGB 硬编码色值、`!important` 暴力覆盖次数，督促收敛进 `DESIGN.md` 与 `tokens.css`。

## 3. 创作者人话体检报告输出规范

执行 `govern.js` 后，向用户呈现清爽的三段式白话报告：
- **🟢 健康指标**：核心功能文件数、已沉淀的设计 Token 数、快照保护状态。
- **🟡 建议瘦身项**：哪几个文件超过了 300 行、哪几处存在硬编码色值或未清理的死函数。
- **🗑️ 一键除草建议**：列出可安全移入归档的过期草稿文档或陈旧快照，经用户点头后执行物理清理。
